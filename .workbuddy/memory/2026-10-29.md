## 模板库"爬虫式"扩充方案（10-29 下午）
- 用户诉求：不要本地手写模板，要像爬虫一样抓免费模板底图，用现有排版引擎叠标题文案生成海量模板
- 方案落地：新增 server/src/scripts/sync-templates.js（npm run sync:templates）
  - 用关键词池批量调 Pexels 搜索抓高清底图（需 PEXELS_API_KEY，免费）
  - 无 Key 时回退 Picsum（免 Key 随机图）保证链路可跑通
  - 每张底图套 generateLayouts 4 版式之一 + 示例文案，renderPoster 渲染 PNG 入 templates 表
  - 可反复运行增量扩充；支持命令行传关键词 `node src/scripts/sync-templates.js "咖啡,旅游"`
- 已验证：旅游/宠物/咖啡 3 关键词生成 12 模板，渲染质量好（标题清晰、排版美观）；模板总数 46→58
- 关键限制：Picsum 图是随机图（与关键词无语义关联），要真实语义配图需配 PEXELS_API_KEY（用户需提供）
- 渲染器 renderer.js 的 drawImage 已支持远程 https URL（assertPublicImageUrl + fetch + 20MB 限制），爬图直接传 URL 即可
