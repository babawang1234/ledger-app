# 2026-10-30 工作日志

## 本轮修复（用户反馈"一键成片无背景/排版单一/手动三模式不通过/不理解关键词"）

### 根因定位
1. **无背景**：`renderer.js` 的 `drawImage` 只把 `/generated/` 前缀转成本地绝对路径，`/ai-images/`、`/design-backdrops/` 等相对路径直接 `loadImage` 失败被 catch 静默吞掉 → 图片层跳过 → 背景空白。
2. **排版单一**：`layouts.js` 的 `photoLayout` 4 个变体只在标题位置微调，视觉雷同。
3. **图文不符**：`local-image-pool.js` 用「整串 includes」匹配（`term.includes(kw)`），导致"新能源汽车充电桩"含"汽车"→误命中跑车、"空气净化器"含"净化"→误命中净水设施。
4. **手动三模式**：前端"设计底图"模式点按钮走了摄影图搜索（`searchStockPhotos`），未独立调用设计底图接口。

### 修复内容
- `renderer.js`：新增 `resolveLocalSource()`，把 `/ai-images/`、`/design-backdrops/`、`/generated/`、`/templates/`、`/uploads/`、`/exports/` 前缀统一解析为 `public` 绝对路径。
- `layouts.js`：`generateLayouts` 改为 4 种差异化照片版式——全幅沉浸 / 上下分栏 / 左右画册（杂志风）/ 杂志封面（大字报），每个都有独立构图。
- `local-image-pool.js`：重写匹配算法——正向最大匹配切词（词典=POOL 所有 keyword/label/category）+ 同义词只对精确词展开 + 「长词主导」歧义消解（query 含 ≥3 字具体词但本地池无命中时返回空，触发 AI 兜底，而非用 2 字宽泛词命中无关图）。
- `image-prompt.js`：新增充电桩/新能源/茶叶/马拉松/家电/中医等中文→英文 prompt 映射；扩充 toRomanized 单字映射。
- `inspire.js`：one-shot 增加「设计底图兜底」——本地池未命中且 AI 生图失败时，用主题色设计底图保证始终有背景。
- `Studio.jsx`：新增独立 `generateDesignBackdrops()` 调用 `/assets/design-backdrops`；修正三模式回车/按钮逻辑。

### 验证结果
- "马拉松" one-shot：AI 生图成功，返回真实跑步者照片背景 + 4 个差异化版式（缩略图视觉确认贴题）。
- "水厂" one-shot：本地池命中，4 版式 feature 分别为全幅沉浸/上下分栏/左右画册/杂志封面。
- "新能源汽车充电桩""空气净化器""充电桩""龙井茶叶" → 本地池正确返回空（触发 AI 兜底，不再误命中跑车/净水）。
- 前端 Vite build 通过。

### 已知局限（无法从代码解决）
- Pollinations 匿名层现在间歇性 503（限流更严），本地池未命中的词可能生图失败，只剩设计底图兜底。
- 所有 API Key 仍为空（DEEPSEEK/OPENAI/UNSPLASH/PEXELS/DASHSCOPE 全空），无真实文本模型做语义理解，纯规则匹配对长尾词仍有边界。

### 待办

## 去本地化（用户要求：图片来源全部走网络 AI + 免商用图，删除本地图片、清理 C 盘）

### 关键结论
- 图库池 `local-image-pool.js` 本质就是远程 CDN 直链（Unsplash/Pexels 免商用），非本地文件，无需动。
- 模板照片 `template-photos.js` 全部是 Unsplash 远程直链。
- 真正占磁盘的是 `server/public` 下三个「运行时渲染产物」目录：design-backdrops(129M)/templates(61M)/ai-images(2.7M)，共 192M。

### 改造（图片全部不落盘，走 data URL / 远程 URL）
- `assets.js`：AI 兜底生图 + 设计底图 → 改 `encodeBufferToDataUrl` 返回 data URL，删掉 `fs.writeFileSync` 落盘。
- `inspire.js`：`/ai-background` 三处落盘（万相/Pollinations/设计底图）+ one-shot 两处落盘 → 全改 data URL；删掉无用的 path/fs import。
- `render-templates.js`：不再渲染 PNG 落盘，`imageUrl` 直接返回远程照片 URL。
- `sync-templates.js` / `ai-templates.js`（手动脚本）：改不落盘，缩略图用远程照片 URL / data URL。
- `.gitignore`：新增 `server/public/templates/*` 忽略。

### 清理动作
- 删除三个目录 388 个图片文件，`server/public` 从 192M → 152K。
- 数据库迁移：180 个模板 `thumbnail_path` 从本地 PNG 路径 → 远程照片 URL（从 layers 的 image 层 src 提取）。
- WAL checkpoint：`data/app.db` 从 4.1M → 1.7M。

- 项目整体 366M → 173M（省 193M）。
